# java-spring-sandbox
Repo to test Spring features

In questo esempio, utilizziamo anche Spring MVC (Model, View, Controller).

La classe "BookController" agisce da CONTROLLER.
L'annotation @Controller indica il comportamento che deve assumere la classe: 
nel nostro caso, deve accettare le richieste provenienti dall'esterno.

La classe "Book" agisce da MODEL, poiche' recupera i dati e li modella per mostrarli.

Le classi che agiscono da VIEW, sarebbero quelle del FE:
in questo caso non sono state definite, ma basti sapere che le VIEW si occupano di mostrare i dati.
